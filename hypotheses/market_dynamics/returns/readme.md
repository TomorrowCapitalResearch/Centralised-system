# Participation, returns and volatility

[Category index](../START_HERE.md) · [Source guide](../source_index/Sources.md)

**What does volume say about size or direction?** Same-bar association, forward risk, dollar volume and directional asymmetry.

The earlier six-coin comparison found forward volatility 8.6% lower after 10 of 15 below-normal-volume minutes at equal current volatility. The effect was 4.3% for 20 of 30 and did not survive the same control at 40 of 60. (LOG/V-32, HYP.)

**Test design.** State whether the outcome is contemporaneous absolute return, forward absolute return, forward realised variance or signed return. Use disjoint feature and target windows and a baseline using the current volatility state.
