# Trend, breakouts and price paths

[Category index](../START_HERE.md) · [Source guide](../source_index/Sources.md)

**When does a directional move continue?** Runs, path efficiency, confirmed breaks, trend anatomy and failed breaks.

Hourly momentum tilted the next 12 h return by 0.027σ per σ of past 12 h return in the pooled six-coin study. A 1–7 day hourly range breakout showed no robust continuation in 12 pooled rows. These give different starting points for an additional breakout rule. (LOG/TD-01, LOG/TD-02, HYP.)

**Test design.** A trend identified from the whole path can describe that path. A forecast needs a trigger observable at its timestamp. Score direction, move magnitude and trend duration separately. A confirmed pivot starts a test only when confirmed.
