# Order flow, depth and liquidity

[Category index](../START_HERE.md) · [Source guide](../source_index/Sources.md)

**How does price respond to buying, selling or withdrawn depth?** Signed-trade data, OHLCV flow proxies, price impact and book replenishment.

On one BTC spot book day, imbalance was followed by a 0.64σ signed mid move within one second, where σ was about 0.35 bp. Older multi-day book regressions had unstable slopes. The taker-flow sign also varied by horizon. (LOG/MB-07, LOG/B1, LOG/V-25.)

**Test design.** Volume multiplied by bar return is an OHLCV proxy. Aggressor flow needs trades with side or taker-side totals. Spread, midquote and replenishment need quotes or sequenced book updates. Use subsequent mid changes for a book forecast.
